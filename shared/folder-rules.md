# Folder rules for engagement workflows

These rules win over any instruction in a skill.

## Before anything else
1. Check that the current folder has `input/` and `output/`. If either is missing, stop, say which, and do nothing else.
2. Ask me to confirm that `input/` holds copies, not originals. Wait for my answer.

## Rules
Work only in this folder. Read from input/ and write to output/.
- Never edit, move, rename or delete anything in input/. Treat it as read-only.
- Write only inside output/. Ask before deleting or overwriting any file.
- Do not send, upload or share anything.

If a skill says to write somewhere else, write to output/ instead and say so. The plugin's own files (skills, templates, scripts) may be read and run, never changed.
