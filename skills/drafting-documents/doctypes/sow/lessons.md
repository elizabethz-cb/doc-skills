# Lessons for the SOW (grows over time)

Claude reads this file before every SOW. Keep each lesson to one or two lines, with the date. Merge repeats into rules.md now and then.

- 2026-11-03: Notes often give both a go-live date and a change-freeze period that overlap. Never pick one. Raise it as a schedule question.
- 2026-11-03: Customers often quote a server count in a meeting and a different one in the inventory. The inventory wins, but record the difference as an open question about peak load.
